How to deploy on cPanel:
======================================
1. Create a new database and user and assign all privileges to the user.
2. Update the .env file with the new database credentials.
3. Import Exported database using phpMyAdmin.
4. Prepare deployment files for production.
5. prepare .env file for production.
6. Delete hot file from public directory if exists.
7. .htaccess file setup in public directory.
8. .htaccess file setup in root directory.

======================================
Troubleshooting:
1. .htaccess file not working, rename htaccess.txt to .htaccess
2. 500 internal server error, check storage and bootstrap/cache permission 775 or 777
3. hot file exists in public directory, delete it.
4. php version not supported, change php version to 8.0 or above.
5. database connection error, check database credentials in .env file.
