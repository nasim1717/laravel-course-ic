8. More Advanced Level Line By Line Execution PHP Xdebug (Deplopment Purpose)
    - Step Over -> Go For Next Execution
    - Step Into -> Go Inside functions
    - Step Out -> Out Inside functions
    - View Break Points-> Show All Break Points Inside Your Project
    - Mute Break Points-> Skipping The Break Points
    - Stop -> Debugging Stop
    - Resume-> Resume The The Execution Process
    - Threads & Variables -> Shows What happpnening Inside Execution
    - Console/Output -> Console print 
    - Evaluate Expression -> Playing With Your Already Executed Expressions and codes



9. 

- Paste `XDebug` dll file inside XAMPP/php/ext 
- Open php.ini and add properties 

- `xdebug.mode=debug`
- `xdebug.start_with_request=yes`
- `xdebug.client_port=9003`
- `xdebug.client_host = localhost`
- `zend_extension="C:\xampp\php\ext\xdebug.dll"`


- Again check PHP version in terminal` php -v`
